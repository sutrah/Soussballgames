Room — Énigmes à plusieurs

Une room se crée avec un simple code à partager (pas de compte). Les joueurs se connectent en pair-à-pair (WebRTC) et voient leurs silhouettes, détectées par pose, évoluer ensemble dans la même scène.

  • Connexion — hôte génère un code de room, les autres le saisissent pour rejoindre en P2P, sans serveur de jeu.
  • Silhouettes partagées — chaque joueur envoie ses repères de pose (pas la vidéo) ; tout le monde voit tous les avatars dans la même pièce.
  • Énigmes à contrainte de nombre — chaque niveau n'est résolvable qu'avec le nombre exact de joueurs prévu (2, 3 ou 4).
  • Exemple prévu — 5 niveaux pour 2 joueurs : leviers à actionner en miroir, plateforme qui ne tient que si les deux joueurs lèvent le bras en même temps, code à composer en tenant une pose chacun sur un chiffre, etc.
  • Scalabilité — les mêmes mécaniques seront déclinées pour 3 et 4 joueurs avec des variantes plus complexes.
